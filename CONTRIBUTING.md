# Contribution à Kauri

Merci de votre intérêt pour la contribution à Kauri ! Nous accueillons avec plaisir les contributions de chacun pour aider à rendre cet outil de gestion financière encore meilleur.

## 🚀 Commencer

1.  **Forkez le dépôt** sur votre propre compte GitHub.
2.  **Clonez le fork** sur votre machine locale :
    ```bash
    git clone https://github.com/VOTRE_NOM_UTILISATEUR/kauri.git
    ```
3.  **Installez les dépendances** :
    ```bash
    npm install
    ```
4.  **Créez une branche** pour votre fonctionnalité ou correction :
    ```bash
    git checkout -b feature/nom-de-votre-fonctionnalite
    ```

## 🛠️ Standards de Code

- **TypeScript** : Tout nouveau code doit être écrit en TypeScript.
- **Prettier** : Nous utilisons Prettier pour le formatage du code. Lancez `npm run format` avant de commiter.
- **Linting** : Assurez-vous que votre code passe tous les tests de lint.
- **Commits** : Utilisez des messages de commit descriptifs (ex: `feat: ajout des transactions récurrentes`).

## 🧪 Tests

- Avant de soumettre une pull request, assurez-vous d'avoir testé vos changements localement.
- Si vous ajoutez une nouvelle fonctionnalité, ajoutez des tests si possible.

## 📬 Soumettre une Pull Request

1.  Poussez vos changements sur votre fork.
2.  Ouvrez une Pull Request (PR) contre la branche `main` du dépôt original.
3.  Fournissez une description claire des changements et pourquoi ils sont nécessaires.

## ⚖️ Licence
